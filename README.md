# 노트북 반납 확인 웹앱 (템플릿)

담임선생님이 **반별 링크**로 들어가 명렬표에 반납 물품(노트북·충전기·충전케이블)을 체크하면, 학교 구글 스프레드시트에 바로 모이는 웹앱입니다.

- 담임선생님: 로그인 없이 링크만 누르면 우리 반 명렬표가 열려요. **[모두]** 체크 → **[✅ 확인]**으로 끝이에요.
- 관리자: 반별 진행률, 미제출·물품 누락 학생, 반별 링크 복사, 제출삭제, 엑셀 다운로드를 할 수 있어요.
- 학생 정보는 **각 학교의 구글 시트에만** 저장돼요. 이 GitHub 화면은 데이터를 저장하지 않고 화면만 보여줘요.

```
담임 휴대폰/PC ──(반별 링크)──▶ 화면 (이 GitHub Pages, 모든 학교 공용)
                                   │  링크의 api 값 = 우리 학교 Apps Script
                                   ▼
                          우리 학교 구글 시트 + Apps Script
```

📄 **한 장으로 보는 안내: [사용방법.pdf](사용방법.pdf)**

## 설치하기

### A. 템플릿 사본 링크를 받은 경우 (추천, 약 10분)
1. 받은 링크를 열고 **[사본 만들기]**를 누릅니다. Apps Script도 함께 복사돼요.
2. 사본 시트의 **[사용방법]** 탭을 따라 합니다.
   1. **[학생입력]** 탭에 학번(5자리)과 이름을 붙여넣어요.
   2. 메뉴 **📦 노트북 반납 → 1. 학생명단 반영하기**
   3. **[설정]** 탭에서 제목과 관리자 비밀번호를 정해요.
   4. **확장 프로그램 → Apps Script → 배포 → 새 배포**에서 웹 앱을 고르고, 실행은 **나**, 액세스는 **모든 사용자**로 둔 뒤 배포해요. 나오는 URL을 복사해요.
   5. **[설정]** 탭 **웹앱 URL** 칸에 붙여넣고, 메뉴 **2. 반별 링크 만들기**
   6. 관리자 링크에 접속해서 **[반별 링크 → 전체 복사]**를 누르고 담임선생님들께 보내요.

### B. 처음부터 직접 만드는 경우
1. 이 저장소의 [`노트북반납_템플릿.xlsx`](노트북반납_템플릿.xlsx)를 내려받아 구글 드라이브에 올려요.
2. 파일을 열고 **파일 → Google Sheets로 저장**을 눌러요.
3. **확장 프로그램 → Apps Script**를 열고, `Code.gs` 내용을 모두 지운 뒤 이 저장소의 [`Code.gs`](Code.gs)를 붙여넣고 저장해요.
4. 시트를 새로고침하면 **📦 노트북 반납** 메뉴가 생겨요. 그다음은 A의 2번과 같아요.

### 다른 선생님께 템플릿 나눠주기
B로 만든 시트에 **학생 정보를 넣기 전에**, 공유 링크 끝의 `/edit…` 부분을 `/copy`로 바꿔서 보내면 돼요. 받은 선생님이 링크를 열면 바로 사본 만들기 화면이 떠요.
```
https://docs.google.com/spreadsheets/d/시트아이디/copy
```
시트 공유 설정은 **링크가 있는 모든 사용자 – 뷰어**로 해 두세요.

## 보안·개인정보
- **학생 정보는 각 학교의 구글 시트에만 저장돼요.** 학생 이름이나 체크 결과는 담임선생님 브라우저와 그 학교 Apps Script 사이에서 바로 오가고, GitHub를 거치지 않아요.
- 이 저장소에는 화면 코드와 빈 템플릿만 있어요. 저장소 주인도 다른 학교의 시트, 학생 정보, 접속 기록을 볼 수 없어요.
- 반 링크를 가진 사람은 그 반 명렬표(번호·이름·체크)를 볼 수 있어요. 학번과 시리얼번호는 반 화면에 나오지 않아요. 전체 명단은 관리자 비밀번호가 있어야 볼 수 있어요.
- 다만 화면 코드는 이 저장소에서 내려받아요. 우리 학교가 직접 관리하는 화면을 쓰고 싶다면 아래처럼 Fork해서 쓰세요.

### 우리 학교 화면을 따로 두기 (Fork)
1. 이 저장소 오른쪽 위 **Fork**를 눌러 내 GitHub 계정으로 복사해요.
2. 내 저장소에서 **Settings → Pages → Branch: `main` / `(root)` → Save**를 눌러요.
3. 1~2분 뒤 생기는 주소(`https://내아이디.github.io/notebook-return-template/`)를 복사해요.
4. 구글 시트의 Apps Script에서 `Code.gs` 맨 위 `FRONT_URL`을 그 주소로 바꾸고 저장해요.
5. 시트 메뉴 **2. 반별 링크 만들기**를 다시 누르면 링크가 내 화면 주소로 바뀌어요.
   - 관리자 화면의 반별 링크는 접속한 주소를 기준으로 만들어져서, 새 관리자 링크로 들어가면 자동으로 맞춰져요.
   - 웹앱 주소는 그대로라 Apps Script를 다시 배포할 필요는 없어요. 단, 웹앱 주소로 직접 들어갔을 때 나오는 관리자 링크는 새 버전으로 배포해야 바뀌어요.

## 시트 구성
| 탭 | 내용 |
|---|---|
| 사용방법 | 설치·사용 안내 |
| 학생입력 | 학번(5자리)·이름·시리얼번호(선택)·비고(선택). 학번 `30101`은 3학년 1반 1번으로 처리돼요 |
| 반납현황 | 최종 수합 파일. 학생 1명당 1행 (노트북/충전기/충전케이블 O, 상태, 제출시각) |
| 담임설정 | 반 · 담임선생님 · 링크키 · 반별 링크 (메뉴로 자동 생성) |
| 설정 | 제목 · 관리자비밀번호 · 웹앱 URL · 관리자 링크 |

## 자주 묻는 것
- **학생이 바뀌었어요**: [학생입력]을 고친 뒤 **1. 학생명단 반영하기**를 다시 누르세요. 이미 체크한 기록은 남아요.
- **반 링크가 학생에게 퍼졌어요**: [담임설정]에서 그 반 링크키를 지우고 **2. 반별 링크 만들기**를 누르세요. 새 링크가 생기고 예전 링크는 막혀요.
- **비밀번호·제목·담임 이름을 바꾸고 싶어요**: 시트에서 고치면 바로 반영돼요. 다시 배포할 필요 없어요.
- **Code.gs를 고쳤어요**: Apps Script에서 **배포 → 배포 관리 → 연필 → 새 버전**으로 배포하세요. "새 배포"를 누르면 주소가 바뀌어서 링크를 다시 만들어야 해요.
- **왜 Apps Script 화면만 쓰지 않나요?**: 구글 계정 여러 개로 로그인한 브라우저에서는 Apps Script 웹앱이 "현재 파일을 열 수 없습니다" 오류를 내요. 그래서 화면은 GitHub Pages에 두었어요.

- [`사용방법.pdf`](사용방법.pdf): 설치·담임 체크·관리자 수령확인 안내 (A4 2쪽, 원본 `사용방법.html`)
