📦 노트북 반납 웹앱 사용방법

담임선생님은 링크로 들어가 체크만, 관리자는 물건을 받은 뒤 수령확인만 누르면 됩니다.

① 설치관리자가 한 번만
(약 10분)
▶
② 링크 보내기반별 링크를
담임선생님께
▶
③ 담임 체크명렬표에 체크 후
[✅ 확인]
▶
④ 수령확인관리자가 물건 받고
체크 후 [✅ 확인]

① 처음 설치 관리자 · 한 번만

  1. 템플릿 링크를 열고 사본 만들기를 누릅니다.
  2. [학생입력] 탭에 학번(5자리)과 이름을 붙여넣습니다. 시리얼번호·비고는 넣지 않아도 됩니다.
  3. 메뉴 📦 노트북 반납 → 1. 학생명단 반영하기를 누릅니다.
    메뉴가 안 보이면 새로고침하세요. 처음 실행할 때 권한 허용 창이 뜨면 허용합니다.
  4. [설정] 탭에서 제목과 관리자 비밀번호를 정합니다. [담임설정] 탭에 담임선생님 이름을 적습니다.
  5. 확장 프로그램 → Apps Script → 배포 → 새 배포에서 웹 앱을 고릅니다.
    실행: 나 / 액세스: 모든 사용자로 두고 배포한 뒤, 나오는 웹앱 URL을 복사합니다.
  6. [설정] 탭 웹앱 URL 칸에 붙여넣고, 메뉴 2. 반별 링크 만들기를 누릅니다.

② 담임선생님께 링크 보내기 관리자

  1. [설정] 탭의 관리자 링크로 들어가 관리자 비밀번호를 입력합니다.
  2. 반별 링크에서 전체 복사를 눌러 메신저로 담임선생님들께 보냅니다.
반 링크에는 비밀 키가 들어 있어 로그인 없이 바로 열립니다. 학생에게는 보내지 마세요.
링크가 퍼졌다면 [담임설정]에서 그 반의 링크키를 지우고 2. 반별 링크 만들기를 다시 누르세요. 예전 링크는 막힙니다.

③ 담임선생님이 할 일 담임

  1. 받은 링크를 누르면 우리 반 명렬표가 열립니다.
  2. 학생이 낸 물품에 체크합니다. 다 냈으면 모두를 체크하면 노트북·충전기·케이블이 한 번에 체크됩니다.
  3. 아래 ✅ 확인을 누르면 저장됩니다. 누른 시각이 제출시각으로 기록되고, 이름 옆에 날짜(월.일.)가 표시됩니다.
  4. 체크한 물품을 관리자에게 전달합니다.
잘못 체크했다면 🔄 조회로 새로 불러온 뒤 체크를 고치고 다시 ✅ 확인을 누르면 됩니다.

④ 관리자가 물건 받고 수령확인 관리자

  1. 관리자 링크로 들어가 비밀번호를 입력합니다.
  2. 제출 시간대별을 봅니다. 담임선생님이 ✅ 확인을 한 번 누를 때마다 한 묶음이 생깁니다.
    예) "3-2 · 11.4. 10:20 · 노트북 10대" → 지금 받은 10대가 누구 것인지 바로 확인할 수 있습니다.
  3. 받은 물건과 개수가 맞으면 그 묶음의 수령확인을 체크합니다. 학생별로 따로 체크해도 됩니다.
    학생별 명단의 수령확인 맨 위 체크박스를 누르면, 지금 화면에 보이는 학생이 모두 체크됩니다.
  4. 화면 아래 ✅ 확인을 눌러야 한 번에 저장됩니다. 저장하기 전에는 시트에 기록되지 않습니다.

관리자 화면에서 할 수 있는 것

반별 현황반마다 제출 인원, 미제출, 수령확인 인원을 봅니다.
학생별 명단반·상태·이름으로 거르고, 물품 체크를 직접 고친 뒤 ✅ 확인으로 저장합니다.
제출삭제잘못 제출된 학생을 미제출로 되돌립니다.
엑셀(.xlsx) 다운로드최종 수합 결과를 엑셀 파일로 받습니다. 구글 시트 [반납현황] 탭에서도 볼 수 있습니다.

자주 묻는 것

학생이 바뀌었어요[학생입력]을 고친 뒤 1. 학생명단 반영하기를 다시 누르세요. 이미 체크한 기록은 남습니다.
비밀번호·제목·담임 이름 변경시트에서 고치면 바로 반영됩니다. 다시 배포하지 않아도 됩니다.
담임이 물품을 고쳤어요물품이 바뀐 학생은 수령확인이 풀립니다. 물건을 다시 확인하고 체크하세요.
"현재 파일을 열 수 없습니다"웹앱 URL이 아니라 받은 링크(github.io 주소)로 들어가세요.
학생 정보는 어디에 저장되나요?우리 학교 구글 시트에만 저장됩니다. 화면(GitHub)에는 저장되지 않습니다.
